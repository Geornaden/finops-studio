📖 Technical Guide: Australian CEMTEX .ABA Record Structure

The Australian Direct Entry CEMTEX specification requires three record types formatted to exactly 120 bytes per row:

Record Columns Field Name Format & Description
Type 0 01 - 120 Descriptive Record Reel 01, User Bank (e.g. CBA), Remitter Name (26 chars), APCA ID (6 digits), Description (12 chars), Date (DDMMYY)
Type 1 01 - 120 Detail Record Payee BSB (XXX-XXX), Account (9 chars), Tx Code 53, Net Amount in Cents (10 digits), Account Name (32 chars), Reference (18 chars), Trace BSB/Acct, Remitter Name
Type 7 01 - 120 File Total Record BSB 999-999, Total Net Amount (10 digits), Total Credit (10 digits), Total Debit 0000000000, Count of Records (6 digits)
