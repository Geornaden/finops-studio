Top 4 CPA-005 Upload Rejections (Code 900) Solved

        
    
          
  • Reversed Cheque MICR Order: Cheques show Transit-Inst (10242-004), whereas CPA-005 requires 0 + Inst + Transit (000410242).
    • 
          
  • Duplicate File Creation Number (FCN): Cols 21–24 (0001–9999) must increment on every submission to RBC/TD/BMO.
    • 
          
  • Short Final Record C Line: Even if your last line has only 1 or 2 payees, bytes 0265–1464 must be space-padded to exact 1,464 chars.
    • 
          
  • 5-Digit vs 6-Digit Julian Date: CPA-005 mandates leading '0' (0YYDDD, e.g. 026322), unlike UK BACS (' 26322').

Frequently Asked Canadian CPA-005 & Rule H1 EFT Questions

      

        
Can the same CPA-005 format handle both CAD and USD Canadian bank accounts?

        
Yes. Record A columns 56–58 specify either CAD or USD (note that USD EFT batches must settle between USD-denominated accounts held at Canadian financial institutions under Payments Canada rules).

      

      

        
Why should B2B SaaS & wholesale platforms use CPA Code 700 instead of 450 for commercial Pre-Authorized Debits?

        
Tagging commercial B2B collections with CPA Code 700 (Business PAD) classifies the entry under Payments Canada Rule H1 Business PAD rules—limiting unauthorized/dispute return windows (`Code 920`) to 10 business days instead of the 90 calendar days granted to consumer Personal PADs (`Code 916`).
