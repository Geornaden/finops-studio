Frequently Asked Questions

      

        
How do I download the generated XML, .ACH, or .ABA file in Retool without corrupting UTF-8 or trailing spaces?

        
In Retool's query Success event handler, run a 1-line script: utils.downloadFile(exportBankBatch.data[0].fileContent, exportBankBatch.data[0].fileName, 'text/plain'). Because FinOps Studio returns exact 94-char (NACHA), 100-char (BACS), or 120-char (ABA) lines as an intact string inside JSON, Retool's browser download preserves every space-padded fixed-width column.

      

      

        
Can Bubble.io apps call these synchronous endpoints without hitting Bubble's webhook timeout?

        
Yes. Synchronous batches up to hundreds of rows execute in 1.2–3.0 seconds via /run-sync-get-dataset-items, well inside Bubble API Connector's timeout window. For 10,000+ row enterprise payroll runs, call /runs asynchronously with a Bubble backend webhook URL.
