Frequently Asked Questions

      
        

          
How does ABA routing checksum validation prevent ACH return fees?

          
Every 9-digit routing number is checked against the Federal Reserve 10-point weighted checksum formula (3-7-1 weights mod 10 = 0) before the batch is created.

        

      
        

          
Does it pad files with 9999... blocking lines?

          
Yes. Every generated NACHA file includes exact Record 1, 5, 6, 8, and 9 headers/controls plus automatic block-factor-10 9999... padding lines.
